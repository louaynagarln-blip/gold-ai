## لماذا تغيرت البنية؟

FxPro يدعم Expert Advisors على MT5 رسمياً. مكتبة MetaTrader5 الرسمية تتواصل مع طرفية MT5 المكتبية؛ ليست API عامة لحساب FxPro يمكن استدعاؤها من Android مباشرة.
لم نثبت أهلية هذا الحساب لواجهة FIX أو غيرها. لن نفترض وجود API مستقل.

المصادر الرسمية:
- https://www.fxpro.com/trading-tools/algo-trading
- https://www.mql5.com/en/docs/python_metatrader5
- https://www.mql5.com/en/docs/python_metatrader5/mt5accountinfo_py
- https://www.mql5.com/en/docs/python_metatrader5/mt5ordercalcprofit_py

البنية الحالية: Android ← HTTPS محمي ← خدمة Python ← مكتبة MetaTrader5 ← طرفية MT5 على Windows.
المحرك يستعمل شموعاً مغلقة M1 وM5 من الطرفية. يرفض الشموع القديمة أو الناقصة والأسعار القديمة أو المستقبلية.
يحسب EMA وRSI وATR والزخم، ويضع خطة محاكاة بشرط توافق الاتجاهين.
يحسب اللوت نزولاً وفق خسارة وقف الحماية بمكتبة الوسيط، مع احتياط انزلاق وعمولة قابلة للضبط.
لا توجد ضمانة بأن خسارة صفقة فعلية ستلتزم بالمبلغ عند فجوة سوق أو انزلاق يتجاوز الاحتياط.

## الموجود فعلياً

- تحقق من `trade_mode == ACCOUNT_TRADE_MODE_DEMO` ورقم حساب متوقع وخادم متوقع وعملة USD وشركة FxPro. يفحص الهوية مرتين بكل دورة؛ لا يعتمد على كلمة Demo.
- المحاكاة متوقفة بعد إعادة تشغيل التطبيق أو الخدمة، ولا تستأنف تلقائياً.
- STOP محلي فوري؛ تأكيد الخادم يظل غير مؤكد عند انقطاع الإنترنت، ولهذا تظهر رسالة واضحة.
- مهلة نبض 10 ثوانٍ للمحاكاة؛ مغادرة واجهة Android ترسل STOP وتوقف النبض.
- رفض مرشح جديد مع أي صفقة أو أمر مفتوح على الحساب، أو حالة مجهولة.
- المخاطرة الافتراضية $0.50 وحد خسارة $2.00، رأس المال المرجعي المذكور $100 لا يُفترض أنه رصيد الوسيط.
- حد الخسارة يعتمد **إجمالي الخسائر المحققة وتكاليفها دون تعويضها بالأرباح + الخسارة العائمة**. اليوم يبدأ 00:00 UTC بهذه النسخة؛ ليس يوم خادم FxPro ولا توقيت لبنان.
- رفض الحد الأدنى للوت عندما يتجاوز المخاطرة المستهدفة.
- تكاليف الوسيط غير مؤكدة افتراضياً؛ لا تنتج خطة مقبولة قبل تأكيدها.
- SQLite لسجل القرارات والأخطاء والإعدادات المتغيرة (لا كلمات مرور).
- رمز HTTPS في ذاكرة Android فقط؛ عنوان الخادم وحده محفوظ. لا تحويلات HTTP ولا تعطيل لفحص الشهادات.
- لا endpoint للتداول. خيار التشغيل يشغل محاكاة بيانات Demo فقط.

## APK والتثبيت على Android

من آخر بناء ناجح في GitHub Actions حمّل artifact باسم AI-GOLD-TRADER-DEMO-APK، فك ZIP ثم ثبّت app-debug.apk.
فعّل السماح بالتثبيت من هذا المصدر إذا طلب Android ذلك. لا تمنح Accessibility؛ ليست مطلوبة.
هذا APK موقّع بمفتاح debug خاص بالبناء، وليس إصدار إنتاج بمفتاح إصدار دائم. قد يلزم حذف نسخة سابقة عند اختلاف التوقيع، مع فقد بياناتها المحلية.
بعد الفتح يبقى غير متصل إلى حين وجود خادم MT5. لا تضع كلمة مرور FxPro في حقول التطبيق.
استخدم عنوان HTTPS ورمز ربط الخدمة فقط. التطبيق لا ينشئ خادماً تلقائياً.

## تشغيل الخدمة — للمشرف على الخادم فقط

المستخدم لا يحتاج تعديل ملفات أو كتابة كود على هاتفه. هذه تعليمات نشر للمشرف عند توفير Windows VPS.

1. تثبيت FxPro MT5 على Windows وتسجيل الدخول **Demo** فيه بصورة تفاعلية. لا تُرسل كلمة المرور بالمحادثة.
2. تثبيت Python المتوافق ومكتبة MetaTrader5 الرسمية. لم تُثبّت هذه المكتبة في بيئة Linux الحالية.
3. تعريف GOLD_DEMO_LOGIN وGOLD_DEMO_SERVER بالقيم المطابقة للطرفية، وGOLD_SYMBOL بالرمز الصحيح من مواصفات الوسيط، وGOLD_BRIDGE_TOKEN برمز عشوائي قوي لا يقل عن 32 حرفاً.
4. تشغيل `python -m engine.server` من جذر المشروع. الخدمة تستمع على 127.0.0.1:8765 فقط.
5. وضعها خلف HTTPS reverse proxy بشهادة صحيحة، وحماية الشبكة وتقييد الوصول ومعدل الطلبات. لا تعرّض منفذ HTTP مباشرة للإنترنت.
6. ربط Android عبر عنوان HTTPS ورمز الخدمة، ثم اختبار القراءة والمحاكاة.

يجب إضافة تدوير السجل والنسخ الاحتياطي وتنظيف بيانات الحساب المحفوظة في سجل الخطط قبل نشر دائم. رمز الربط يعطى للمستخدم عبر قناة آمنة؛ لا يكتب بالمستودع.
