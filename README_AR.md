# AI GOLD TRADER 0.4 — تحكم الشاشة

الإصدار الحالي يستخدم Android Accessibility، دون خادم MT5 أو API أو شرط تحقق Demo. أُزيلت صلاحية الإنترنت من تطبيق Android.

يمكنه اكتشاف FxPro المثبّت وفتحه، ومراقبة عناصر الشاشة، وتصدير تقريرها، واختيار عنصر فريد للضغط عليه مرة واحدة أو الكتابة في حقل ذي معرّف. يمنع الإجراء إذا تغيّرت الشاشة أو تعذر تحديد العنصر.

**ليس روبوت تداول مكتمل:** لا توجد بعد قراءة موثوقة لشموع الرسم أو استراتيجية مرتبطة بالشاشة أو تسوية وتأكيد صفقات FxPro. يجب فحص تقرير عناصر FxPro من الهاتف قبل بناء تسلسل تداول موثوق؛ لا تُستخدم إحداثيات تخمينية.

[التثبيت والخطوة المطلوبة على الهاتف وحدود التحكم](docs/SCREEN_CONTROL_AR.md)

الاختبارات الحالية تتضمن اختبارات سياسة تحديد العناصر واختبار Accessibility على واجهة محلية في المحاكي. لا تثبت عمل التداول داخل FxPro.

نسخة APK موقعة Debug وليست إصدار إنتاج بمفتاح توقيع دائم. اختلاف توقيع نسخة سابقة قد يستلزم حذفها قبل تثبيت هذه النسخة.
